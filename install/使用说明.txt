Nientum Studio · 谱面工坊（实验版 · 多向斜轨 & 直线投影）
版本：Exp-v1（2026-11-22，含自包含实验版编辑器 + 配套游戏 Mod v1.0.2-exp）

============================================================
一、与正式版完全隔离说明
============================================================
  - 本实验版自带独立 .NET 运行时与独立工作目录，解压即用，不会覆盖或影响
    正式版（NientumStudio-v3-2026.11.22）的程序、设置与桌面快捷方式。
  - 双击 安装.bat 一键全自动完成：
    1) 如果游戏尚未安装 BepInEx，会自动部署内置 BepInEx 框架并生成 BepInEx 文件夹；
    2) 自动把原版/稳定版 Mod 备份为 NientumCustomCharts.dll.stable_bak 再装入实验版 Mod；
    3) 自动创建独立桌面快捷方式「Nientum 谱面编辑器 (实验版)」。
  - 双击 卸载.bat 会删除实验版快捷方式，并自动从 .stable_bak 还原稳定版 Mod。
  - 支持的音频格式：OGG（最推荐）、MP3、WAV、FLAC（不支持 M4A / AAC / 加密格式）。

============================================================
二、实验版核心特性
============================================================
  1. 图层支持任意方向斜轨（-75° ~ +75°）：
     - 左栏图层面板点击「+ 斜轨」一键新增斜行轨道图层；
     - 每张图层卡片新增「方向」滑块与输入框（正值=右上方俯冲，负值=右下方攀升，
       也可直接输入 60 或 -60 等任意角度）。
  2. 同拍 X 坐标对齐保证精准判定：
     - 所有角度的音符在到达判定框同一 X 坐标的瞬间，高度必然同时收敛进
       对应空中/地面判定圈中心，实机游玩时不错位。
  3. 主预览斜轨垂线 + 独立「直轨投影参考框」：
     - 预览标题栏可随时开关「斜轨垂线」与「直轨投影框」；
     - 「直轨投影参考框」将所有斜轨音符与长条垂直投影到人物水平直线上，
       标明所属斜角并支持直接点击放置/删除，方便写谱精确预判打击时机。
  4. 内置实验演示曲：
     - 编辑器\CustomCharts\exp_angled_demo（斜轨实验曲 · 多向来袭 128 BPM），
       含 0° / +35° / -35° / +55° 四层与斜向长条示范，可直接同步到游戏试玩。
  5. 图层整卡点击切换与独占/隔离编辑模式（Solo）：
     - 鼠标点击图层卡片任意空白区域即可直接激活切换当前层（高亮粗边框提示）；
     - 开启顶栏「独占模式」后，界面仅显示并仅允许修改当前激活图层的音符，
       时间轴自动拦截非当前层的拾取与框选，彻底杜绝多轨道写谱误触。
